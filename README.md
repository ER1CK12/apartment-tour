# Прогулка по квартире (демо)

Виртуальный 3D-тур по квартире в браузере: https://er1ck12.github.io/apartment-tour/

- Гостиная и прихожая построены по скану [«Livingroom SLAM scan»](https://sketchfab.com/3d-models/livingroom-slam-scan-61309343675349f48025026ec0aabf97), автор exwayz, CC BY 4.0. Остальные комнаты и отделка добавлены для примера.
- Текстуры: [Poly Haven](https://polyhaven.com), CC0.
- Освещение просчитано в Blender Cycles и запечено в карты освещения; рендер в браузере на three.js.
